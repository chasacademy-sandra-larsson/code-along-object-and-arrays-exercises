# Objekt, arrayer och iterationer

Övningar på objekt och arrayer, och på olika sätt att loopa igenom dem. Börja uppifrån, varje fil bygger lite på den förra. Fortsättningen ligger i [code-along-object-and-arrays-exercises-continued](https://github.com/chasacademy-sandra-larsson/code-along-object-and-arrays-exercises-continued).

## Kom igång

Öppna `index.html` med Live Server och öppna konsolen (F12). Vill du köra en annan övning byter du filnamnet i `<script>`-taggen i `index.html`. Har du Node installerat kan du också köra 01–05 direkt i terminalen, t.ex. `node js/05-array-av-objekt.js`. Övning 06–08 behöver webbläsaren, och 07–08 behöver dessutom Live Server: `fetch` fungerar inte när man öppnar filen direkt.

## Övningarna

| Fil | Vad du övar |
| --- | --- |
| `01-objekt-grunder.js` | Punkt- och bracket-notation, nyckel i en variabel, lägga till, ändra och ta bort, `Object.hasOwn` |
| `02-nastlade-objekt.js` | Objekt i objekt, data som saknas, `?.` och `??` |
| `03-loopa-arrayer.js` | `for`, `for...of` och `forEach`, när man väljer vilken, `break`, varför inte `for...in` på arrayer |
| `04-loopa-objekt.js` | `for...in`, `Object.keys/values/entries` tillsammans med `for...of` |
| `05-array-av-objekt.js` | Hitta, filtrera, plocka ut, summera och jämföra, i funktioner som returnerar |
| `06-rendera-lista.js` | Från data till sidan: rendera en lista, nästlade listor, en funktion som ritar om, tomt läge |
| `07-fetch-json.js` | Hämta en lista från en JSON-fil med `fetch`, `async` och `await`, och rendera den |
| `08-fetch-api.js` | Samma sak, fast från ett öppet API |

Fastnar du: läs uppgiften igen och skriv ut det du har med `console.log` innan du skriver nästa rad. Oftast är det en nivå för mycket eller för lite.
